# Mazak FH680 LinuxCNC retrofit

LinuxCNC retrofit of a Mazak FH680 horizontal machining centre (Y is
vertical), running LinuxCNC 2.10.0~pre1 (uspace, PREEMPT_RT) with Mesa
hardware: 7i92 Ethernet card (10.10.10.10) + 7i77, 7i76, 7i71 and 7i70.

## Folders

| Folder | What |
|---|---|
| `mazakv3/` | **The live config.** Start here: `mazakv3.ini` |
| `mazakv2/` | Previous version, kept for reference |
| `7i96/` | Early config for a 7i96 card, kept for reference |
| `atc.comp`, `mag.comp`, `pallet.comp` | Older comp sources. The current atc/mag are in `mazakv3/comp/`. `pallet.comp` is still the live one |

## mazakv3 highlights

- **Toolchanger** (`toolchanger.hal`, `comp/atc.comp`, `comp/mag.comp`):
  80-pocket random toolchanger. The carousel (joint 5), ATC arm (joint 6) and
  shifter (joint 7) are LinuxCNC extra joints driven through `limit3`. The M6
  remap is in `sub_progs/toolchange.ngc` (orient, move to the change position,
  wait for the pot, swap).
  - Interlocks, timeouts and fault codes, with Reset resuming the step that faulted.
  - Step mode (NEXT button) and slow mode (AXIS Max Velocity slider) for setup.
  - E-stop freezes all toolchanger motion.
  - Pot tracking survives restarts (`magstate.py`).
- **Drawbar** (`comp/drawbar.comp`): manual unclamp button, interlocked against
  a turning spindle / machine off / toolchanger busy; feed and spindle inhibit
  while unclamped.
- **Spindle orient** (`spindle_orient.comp`): M19 via the VFD's step/dir input,
  holding the angle for the toolchange.
- **Panels**: PyVCP side panel (`toolmeasure.xml`, `toolchanger_panel.xml`),
  generated by `build_toolmeasure.py`.
- `LINUXCNC_UPGRADE_NOTES.md`: things to undo or re-check when moving off
  2.10.0~pre1, including a workaround for an abort hang in pre1.

Custom comps are installed with `sudo halcompile --install <file>.comp`.

Not in the repo (see `.gitignore`): machine state (tool table, `linuxcnc.var`,
saved positions), local backups and work-in-progress folders, screenshots and
Mesa's PDF manuals. Mesa manuals: https://mesanet.com
